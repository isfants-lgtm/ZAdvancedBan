# AdvancedPunish

Projeto inicial para Paper 1.21.11 / Java 21 com build automático pelo GitHub Actions.

## Compilação
O workflow `.github/workflows/build.yml` compila em cada push e disponibiliza o JAR em **Actions → workflow → Artifacts**.

## Observação
Este ZIP é uma base inicial compilável, não uma implementação completa de todos os requisitos de produção (Anti-Alt avançado, MySQL, histórico paginado, sincronização entre servidores e testes de carga ainda precisam ser desenvolvidos e validados).
